# Mario Arsyad — Portfolio

Personal portfolio of Mario Arsyad, Data Engineer & Business Intelligence Specialist.

Live: https://mariojofan24.github.io/Portofolio/

## Stack
Astro · Tailwind CSS · GitHub Pages

## Local development
```bash
npm ci
npm run dev
```

Content lives in `src/data/*.json` (profile, career, projects, skills, certifications).

## Deployment
Pushing to `main` builds and deploys to GitHub Pages via `.github/workflows/deploy.yml`.
